    Tile interface
    
      
      
        
    • Drag empty space to move around · scroll wheel or pinch to zoom
      • 
        
    • Touch screens: tap a tile to select it, then drag it to move it; dragging an unselected tile moves the view
      • 
        
    • Double-click (double-tap) empty space for a new task, or a tile to edit it
      • 
        
    • Click a tile to select it · Shift+click, or turn on Select, to select several
      • 
        
    • Shift+drag on empty space (or drag with Select on) for a selection box · Esc clears
      • 
        
    • Drag the red dot onto a tile to make it a Parent, the green dot to make it a Child; again to unlink
      • 
        
    • Drop a dot on empty space for a new linked task · hover or press and hold a tile for its description
      • 
        
    • Auto place lays out every tile, or just the selected ones · Delete in the edit form removes a task
      • 
      
    
    
    
    
    
      
    Text interface
    
      
      
        
    • Tab / Shift+Tab indent or outdent lines · indented = Child of the line above
      • 
        
    • Enter keeps the indentation · Shift+Enter starts a deeper line
      • 
        
    • Ctrl+Enter or Update rebuilds the tiles from the text
      • 
        
    • Ctrl+Space or Hide tags hides the <…> and […] tags
      • 
        
    • Drop a .txt file to open it (Shift to add it below), or use Import .txt
      • 
        
    • Save as .txt saves the text · Save as .html saves a copy of this page that opens with your text · Copy… with or without tags
      • 
        
    • Descriptions are lines starting with // under a task
